TP IoT · ESP32 serveur web

Piloter la LED par une page web hébergée sur l'ESP32

Ici, pas de cloud : l'ESP32 est elle-même un serveur web sur le réseau local. Le navigateur du téléphone lui envoie des requêtes HTTP à son adresse IP, et la carte répond en renvoyant une page qui affiche l'état de la LED.

Requête HTTP navigateur → carte Réponse HTTP carte → navigateur (état de la LED) Fil électrique GPIO 26 → résistance → LED
Carte : éteinte Wi-Fi : actif Téléphone : Wi-Fi local LED : éteinte
Prêt

Ce qui se passe

  1. Cliquez sur « 1. Démarrer la carte » : l'ESP32 va se connecter au Wi-Fi et démarrer son serveur web.
