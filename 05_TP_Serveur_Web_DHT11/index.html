1. Objectifs

  • Réaliser le câblage d'un module capteur DHT11 sur une plaque d'essai et le relier à la carte ESP32.
  • Écrire et tester votre propre programme de mesure dans l'Arduino IDE.
  • Créer le serveur web avec le générateur de tableau de bord : la carte mesure l'air et affiche jauges et courbes sur le réseau Wi-Fi local.
  • Lire la température et l'humidité dans le navigateur d'un téléphone ou d'un ordinateur, sous forme de jauges et de courbes.
  • Récupérer l'historique des mesures dans un fichier CSV et l'exploiter avec un tableur.
  • Comprendre qui demande l'information et qui la fournit, grâce à l'animation fournie.
  • Comparer cette solution avec la plateforme Arduino Cloud.

Ce qui vous est fourni

  • Le générateur de tableau de bord (Generateur_Page_Web_ESP32_etudiant.html, ou en ligne : celdobigeon.github.io/IoT) : c'est avec lui que vous créerez le programme du serveur web.
  • Le programme d'origine : dossier ESP32_Serveur_Web_DHT11 (voir l'annexe). Il sert à la partie 10, « Pour aller plus loin ».
  • L'animation Animation_DHT11_Serveur_Web.html : ouvrez-la dans un navigateur (double-clic).

Votre travail : le câblage, votre programme de mesure, la création du serveur web avec le générateur, les tests et les questions.

3. Le capteur DHT11

Le DHT11 est un capteur bon marché qui mesure la température et l'humidité relative de l'air. Il contient un petit microcontrôleur qui envoie les mesures sous forme numérique sur un seul fil (DATA). Extrait de la fiche technique :

Caractéristique

Valeur

Tension d'alimentation

3,3 V à 5,5 V (ici : 3,3 V)

Température : plage / précision

0 à 50 °C / ± 2 °C

Humidité relative : plage / précision

20 à 90 % / ± 5 %

Résolution

1 °C et 1 %

Temps entre deux mesures

1 s minimum (2 s conseillées)

Sortie

Numérique, un seul fil (trame de 40 bits)

L'humidité relative, c'est quoi ?

C'est la quantité de vapeur d'eau contenue dans l'air, comparée à la quantité maximale que l'air peut contenir à cette température. 100 % = air saturé (brouillard, buée) ; une salle de classe est souvent entre 40 et 60 %.

5. Le câblage

Rappels

  • Le module a 3 broches : S (signal DATA), + (VCC, alimentation) et – (GND, masse). Si les marquages de votre module sont dans un autre ordre, adaptez les colonnes.
  • Alimentez le capteur par la broche 3V3 de la carte, et non par VIN (5 V) : les broches de l'ESP32 n'acceptent pas plus de 3,3 V.
  • Sur la plaque d'essai, les 5 trous d'une même colonne (a à e, ou f à j) sont reliés entre eux.
  • Les lignes bleues (–) et rouges (+) des bords sont reliées sur toute leur longueur.
  • Réalisez tout le câblage carte débranchée.

Schéma de câblage

Schéma électrique

Étapes

  1. Module DHT11 : grille bleue face à vous, enfoncez les broches S, +, – dans les trous a14, a15, a16.
  2. Fil jaune : du côté femelle sur la broche D4 de la carte, du côté mâle dans le trou e14.
  3. Fil rouge mâle-mâle : du trou e15 à la ligne rouge (+) du bas.
  4. Fil noir mâle-mâle : du trou e16 à la ligne bleue (–) du bas.
  5. Fil rouge mâle-femelle : de la broche 3V3 de la carte (en bas à droite) à la ligne rouge (+) du bas.
  6. Fil noir mâle-femelle : de la broche GND de la carte (côté droit, juste au-dessus de 3V3) à la ligne bleue (–) du bas.

6. Mesurer avec votre programme dans l'Arduino IDE

Avant de créer le serveur web, vérifiez votre câblage et le capteur avec un programme que vous écrivez vous-même : il affiche la température et l'humidité dans le moniteur série.

  1. Branchez la carte à l'ordinateur avec le câble micro-USB.
  2. Installez la bibliothèque du capteur : Outils > Gérer les bibliothèques…, cherchez DHT sensor library (auteur : Adafruit), puis cliquez sur Installer. Si l'IDE propose aussi Adafruit Unified Sensor, choisissez « Tout installer ».
  3. Créez un nouveau croquis, Mesure_DHT11 (Fichier > Nouveau croquis). Choisissez la carte (Outils > Carte > esp32 > DOIT ESP32 DEVKIT V1) et le port (Outils > Port).
  4. Écrivez le programme : toutes les 2 secondes, la carte lit la température et l'humidité et les affiche dans le moniteur série. Aide : #include <DHT.h> en haut du programme donne accès au capteur ; DHT dht(4, DHT11); déclare un DHT11 sur la broche D4 ; dans setup(), Serial.begin(115200) et dht.begin() démarrent le moniteur série et le capteur ; dans loop(), dht.readTemperature() et dht.readHumidity() renvoient les mesures, Serial.print() les affiche et delay(2000) attend 2 s.
  5. Quand la lecture échoue, les mesures valent nan (« pas un nombre ») : testez-le avec isnan(t) et affichez alors « Erreur de lecture du DHT11 ! ».
  6. Téléversez (flèche →) et ouvrez le Moniteur série à 115200 bauds. Si le téléversement bloque sur « Connecting… », maintenez le bouton BOOT enfoncé jusqu'au début du transfert.
  7. Soufflez doucement sur le capteur : l'humidité affichée augmente.
  • Une mesure s'affiche toutes les 2 secondes
  • « Erreur de lecture du DHT11 ! » s'affiche quand le fil jaune est débranché

Notez sur votre feuille la température (°C) et l'humidité (%) affichées dans le moniteur série.

7. Créer le serveur web avec le générateur de tableau de bord

Le programme du serveur web, vous le créez sans le programmer, avec le générateur de tableau de bord : vous choisissez ce que la page affiche, le générateur écrit le programme.

  1. Ouvrez le générateur (Generateur_Page_Web_ESP32_etudiant.html, ou celdobigeon.github.io/IoT) et choisissez « Page vide ».
  2. Ma carte : saisissez le nom et le mot de passe du Wi-Fi, ajoutez un Capteur DHT11 sur la broche D4, et choisissez une mesure toutes les 5 s (historique de 30 min). Donnez un nom au programme, par exemple Station_meteo.
  3. Apparence : choisissez le rechargement automatique toutes les 5 s.
  4. Blocs : ajoutez un titre (« Station météo »), l'Alerte capteur DHT11, une jauge pour la température et une autre pour l'humidité, les courbes de la température et de l'humidité, les informations de la carte (âge de la dernière mesure) et le téléchargement CSV. Vous pouvez ensuite changer la forme des blocs ou en ajouter.
  5. Testez dans l'aperçu : bougez les curseurs de simulation, cochez « DHT11 débranché », cochez « La carte mesure en continu ».
  6. Cliquez sur Télécharger le programme, ouvrez le fichier .ino dans l'Arduino IDE et téléversez-le. Si le téléchargement ne démarre pas, utilisez « Copier le programme » et collez-le dans un nouveau croquis.
  7. Ouvrez le Moniteur série (115200 bauds), puis appuyez sur le bouton EN de la carte : l'adresse IP s'affiche après la connexion, puis une mesure toutes les 5 secondes.

Notez sur votre feuille l'adresse IP de votre carte (par exemple 192.168.1.42) : vous en aurez besoin pour ouvrir la page.

  • L'adresse IP s'affiche dans le moniteur série, puis une mesure toutes les 5 secondes

8. Tester

  1. Connectez le téléphone (ou l'ordinateur) au même réseau Wi-Fi que la carte.
  2. Dans le navigateur, tapez http:// suivi de l'adresse IP de la carte (par exemple http://192.168.1.42).
  3. Observez la page : deux jauges (température et humidité), la ligne « Dernière mesure il y a … s » et les courbes de l'historique.
  4. Laissez la page ouverte sans la toucher pendant 2 minutes : elle se recharge toute seule et les courbes s'allongent.
  5. Soufflez doucement sur le capteur pendant 2 à 3 secondes (ou tenez-le entre vos doigts) et observez la page.
  6. Débranchez uniquement le fil jaune, côté carte, pendant une dizaine de secondes : observez la page et le moniteur série. Rebranchez-le.
  • Les deux jauges affichent la température et l'humidité
  • La page se recharge toute seule et les courbes s'allongent
  • L'humidité augmente quand on souffle sur le capteur
  • La page affiche « Erreur de lecture du DHT11 ! » quand le fil jaune est débranché

Notez sur votre feuille l'humidité maximale atteinte après avoir soufflé (%) et le délai avant que la page change (s).

Exploiter le fichier CSV

  1. Laissez la carte mesurer au moins 5 minutes, puis cliquez sur le lien de téléchargement des mesures (CSV) de la page (adresse http://<adresse IP>/mesures.csv). Le fichier mesures.csv est enregistré dans le dossier Téléchargements.
  2. Ouvrez-le avec le tableur. Colonne A : temps en secondes depuis le démarrage de la carte ; colonne B : température (°C) ; colonne C : humidité (%).
  3. Calculez la température moyenne, minimale et maximale avec les formules =MOYENNE(B2:B100), =MIN(B2:B100) et =MAX(B2:B100) (adaptez le numéro de la dernière ligne).
  4. Sélectionnez les colonnes A et C, puis insérez un graphique en nuage de points avec lignes : vous retrouvez la courbe d'humidité de la page web.

Le fichier CSV

CSV (Comma-Separated Values) : un fichier texte où chaque ligne est une mesure et où les valeurs sont séparées par un caractère. Ici, le séparateur est le point-virgule et les nombres ont une virgule décimale, comme l'attend un tableur réglé en français.

Exemple : temps (s);temperature (°C);humidite (%) puis 0;23,0;47,0 puis 5;23,0;48,0

  • Le fichier CSV s'ouvre dans le tableur, en trois colonnes

Notez sur votre feuille le nombre de mesures, puis la température moyenne, minimale et maximale (°C).

9. Questions de compréhension

  1. Dans ce TP, qui joue le rôle de client et qui joue le rôle de serveur ? Quel est le rôle du DHT11 ?
  2. Quand vous ouvrez la page, quelle fonction du programme est exécutée ? Fait-elle une nouvelle mesure ? D'où viennent les valeurs affichées ?
  3. La page se recharge toute seule toutes les 5 secondes. Quelle ligne du programme le demande ? Qui prend l'initiative de ce rechargement : la carte ou le navigateur ?
  4. Pourquoi le programme utilise-t-il millis() plutôt que delay(5000) dans loop() pour attendre entre deux mesures ? Que se passerait-il pour la page web avec delay(5000) ?
  5. Vous soufflez sur le capteur : au bout de combien de temps la page change-t-elle ? Expliquez pourquoi ce délai varie d'une fois à l'autre.
  6. Le fil jaune est débranché : que montrent le moniteur série et la page ? Donnez deux autres erreurs (de câblage ou de programme) qui peuvent produire le même message.
  7. Deux téléphones ouvrent la page en même temps. Affichent-ils les mêmes valeurs ? Le capteur fait-il plus de mesures ? Pourquoi est-ce important pour un DHT11 ?
  8. Ouvrez le fichier mesures.csv. Pourquoi la première colonne donne-t-elle le temps depuis le démarrage de la carte, et non l'heure ? Combien de lignes le fichier peut-il contenir au maximum, et que se passe-t-il ensuite ?
  9. Maintenance : on veut surveiller la température d'une armoire électrique pendant tout un week-end et être prévenu en cas de surchauffe. Le serveur web de ce TP convient-il, ou faut-il Arduino Cloud ? Justifiez avec deux limites (pensez à la durée de l'historique, au redémarrage de la carte et au téléphone en 4G dans l'animation).

10. Pour aller plus loin

Ces trois améliorations se font sur le programme d'origine (dossier ESP32_Serveur_Web_DHT11, voir l'annexe) : ouvrez-le dans l'Arduino IDE, renseignez le Wi-Fi, puis modifiez-le.

A. Alerte de surchauffe

  • Dans la fonction page(), juste après les deux lignes des jauges (avant l'accolade } qui ferme le else), ajoutez :
    if (temperature > 28) {
      html += "<p style='color:#c00'><b>Alerte : température trop élevée !</b></p>";
    }
  • Téléversez, puis tenez le capteur entre vos doigts jusqu'à l'affichage de l'alerte.

B. Température ressentie

  • Ajoutez une variable globale float ressenti = 0; et, dans mesurer(), juste après humidite = h;, la ligne : ressenti = dht.computeHeatIndex(t, h, false);
  • Affichez-la dans page(), sous les jauges, avec : html += "<p>Température ressentie : " + String(ressenti, 1) + " °C</p>";

C. Une adresse pour les machines

  • Ajoutez une deuxième adresse /mesures qui renvoie seulement les valeurs, au format JSON (lisible par un autre programme) :
void handleMesures() {
  String json = "{\"temperature\":" + String(temperature, 1) + ",\"humidite\":" + String(humidite, 0) + "}";
  server.send(200, "application/json", json);
}
  • Dans setup(), sous server.on("/", handleRoot);, ajoutez : server.on("/mesures", handleMesures);
  • Testez l'adresse http://<adresse IP>/mesures dans le navigateur.

11. En cas de problème

Problème

Solution

La carte n'apparaît pas dans Outils > Port

Vérifier le câble micro-USB (données), installer le pilote USB (CP210x), changer de port USB.

Erreur de compilation « DHT.h: No such file or directory »

La bibliothèque DHT sensor library n'est pas installée : refaire l'étape 2 de la partie 6.

Le téléversement bloque sur « Connecting… »

Maintenir le bouton BOOT enfoncé au début du téléversement.

Des points s'affichent sans fin dans le moniteur série

La carte ne trouve pas le réseau Wi-Fi : prévenir l'enseignant.

Rien ne s'affiche dans le moniteur série

Régler la vitesse sur 115200 bauds, puis appuyer sur EN.

« Erreur de lecture du DHT11 ! »

Vérifier les colonnes 14-15-16, le fil jaune sur D4, le fil 3V3, le fil GND et l'ordre des broches du module.

La page ne s'ouvre pas

Vérifier que le téléphone est sur le même Wi-Fi et que l'adresse commence par http:// (et non https://).

Le fichier CSV s'ouvre dans une seule colonne

Tableur réglé en anglais : utiliser Données > Convertir (Excel) ou choisir le point-virgule comme séparateur à l'ouverture (LibreOffice).

Les courbes repartent de zéro

La carte a redémarré (coupure d'alimentation, bouton EN) : l'historique était dans sa mémoire et il est effacé.

La page ne se recharge plus

Le navigateur a affiché une page d'erreur (Wi-Fi coupé, carte redémarrée…) : recharger la page à la main.

Le capteur est chaud

Le + et le – sont inversés : débrancher immédiatement et vérifier le câblage.

Annexe – Programme d'origine (pour la partie 10)

Ce programme sert à la partie 10, « Pour aller plus loin ». Il ressemble à celui que crée le générateur : vous y retrouvez les mêmes lignes que dans l'animation.

// TP IoT - Afficher la température et l'humidité sur une page web hébergée par l'ESP32
// Carte : DOIT ESP32 DEVKIT V1 - module DHT11 : S sur D4 (GPIO 4), + sur 3V3, - sur GND
// Bibliothèque à installer : « DHT sensor library » (Adafruit)
 
#include <WiFi.h>
#include <WebServer.h>
#include <DHT.h>
 
const char* ssid = "NOM_DU_RESEAU";      // nom du réseau Wi-Fi (2,4 GHz)
const char* password = "MOT_DE_PASSE";   // mot de passe du réseau Wi-Fi
 
const int DHT_PIN = 4;                   // broche DATA = D4
DHT dht(DHT_PIN, DHT11);                 // capteur de type DHT11
WebServer server(80);                    // serveur web sur le port 80
 
float temperature = 0;                   // dernière mesure valide (°C)
float humidite = 0;                      // dernière mesure valide (%)
bool erreur_capteur = true;              // vrai tant qu'aucune mesure valide n'a été faite
unsigned long derniereMesure = 0;        // instant de la dernière mesure (ms)
const unsigned long PERIODE = 5000;      // une mesure toutes les 5 s
 
// Historique des mesures, gardé dans la mémoire de la carte (effacé si la carte redémarre)
const int NB_MAX = 360;                  // 360 mesures x 5 s = 30 minutes
float histT[NB_MAX];                     // températures (°C)
float histH[NB_MAX];                     // humidités (%)
unsigned long histTemps[NB_MAX];         // instant de chaque mesure (s depuis le démarrage)
int nbMesures = 0;                       // nombre de mesures enregistrées
 
// Ajoute une mesure à l'historique
void enregistrer(float t, float h) {
  if (nbMesures == NB_MAX) {             // historique plein : on oublie la mesure la plus ancienne
    for (int i = 1; i < NB_MAX; i++) {
      histT[i - 1] = histT[i];
      histH[i - 1] = histH[i];
      histTemps[i - 1] = histTemps[i];
    }
    nbMesures--;
  }
  histT[nbMesures] = t;
  histH[nbMesures] = h;
  histTemps[nbMesures] = millis() / 1000;
  nbMesures++;
}
 
// Demande une mesure au capteur et la garde en mémoire
void mesurer() {
  float t = dht.readTemperature();       // température en °C
  float h = dht.readHumidity();          // humidité relative en %
  if (isnan(t) || isnan(h)) {            // isnan() : la mesure a échoué
    erreur_capteur = true;
    Serial.println("Erreur de lecture du DHT11 !");
  } else {
    erreur_capteur = false;
    temperature = t;
    humidite = h;
    enregistrer(t, h);
    Serial.print("Temperature : ");
    Serial.print(t);
    Serial.print(" C   Humidite : ");
    Serial.print(h);
    Serial.println(" %");
  }
}
 
// Dessine une jauge en demi-cercle (image SVG) : l'arc coloré va de mini à la valeur
String jauge(String titre, float valeur, float mini, float maxi, int decimales, String unite, String couleur) {
  float k = constrain((valeur - mini) / (maxi - mini), 0.001, 1);   // fraction de 0 à 1
  float angle = PI * (1 - k);            // 180° pour mini, 0° pour maxi
  float x = 100 + 80 * cos(angle);       // bout de l'arc coloré
  float y = 100 - 80 * sin(angle);
  String s = "<svg width='200' height='140' viewBox='0 0 200 140'>";
  s += "<path d='M20,100 A80,80 0 0 1 180,100' fill='none' stroke='#ddd' stroke-width='16'/>";
  s += "<path d='M20,100 A80,80 0 0 1 " + String(x, 1) + "," + String(y, 1) + "' fill='none' stroke='" + couleur + "' stroke-width='16'/>";
  s += "<text x='100' y='92' text-anchor='middle' font-size='26' font-weight='bold'>" + String(valeur, decimales) + " " + unite + "</text>";
  s += "<text x='20' y='120' text-anchor='middle' font-size='12'>" + String(mini, 0) + "</text>";
  s += "<text x='180' y='120' text-anchor='middle' font-size='12'>" + String(maxi, 0) + "</text>";
  s += "<text x='100' y='135' text-anchor='middle' font-size='14'>" + titre + "</text>";
  s += "</svg>";
  return s;
}
 
// Dessine les courbes de l'historique (image SVG) : température de 0 à 50 °C, humidité de 0 à 100 %
String courbe() {
  String s = "<svg width='100%' viewBox='0 0 680 260' style='max-width:680px'>";
  for (int i = 0; i <= 4; i++) {         // 5 lignes horizontales de graduation
    int y = 220 - 50 * i;
    s += "<line x1='40' y1='" + String(y) + "' x2='640' y2='" + String(y) + "' stroke='#ddd'/>";
    s += "<text x='34' y='" + String(y + 4) + "' text-anchor='end' font-size='11' fill='#c2410c'>" + String(i * 12.5, 1) + "</text>";
    s += "<text x='646' y='" + String(y + 4) + "' font-size='11' fill='#2b5fd6'>" + String(i * 25) + "</text>";
  }
  String ptsT = "", ptsH = "";           // listes de points "x,y x,y ..."
  for (int i = 0; i < nbMesures; i++) {
    float x = 40 + 600.0 * i / (NB_MAX - 1);
    ptsT += String(x, 1) + "," + String(220 - histT[i] * 200 / 50, 1) + " ";
    ptsH += String(x, 1) + "," + String(220 - histH[i] * 200 / 100, 1) + " ";
  }
  s += "<polyline points='" + ptsT + "' fill='none' stroke='#c2410c' stroke-width='2'/>";
  s += "<polyline points='" + ptsH + "' fill='none' stroke='#2b5fd6' stroke-width='2'/>";
  s += "<text x='40' y='245' font-size='12' fill='#c2410c'>— température (°C)</text>";
  s += "<text x='640' y='245' text-anchor='end' font-size='12' fill='#2b5fd6'>humidité (%) —</text>";
  s += "</svg>";
  return s;
}
 
// Construit la page HTML envoyée au navigateur
String page() {
  String html = "<!DOCTYPE html><html><head><meta charset='utf-8'>";
  html += "<meta name='viewport' content='width=device-width'>";
  html += "<meta http-equiv='refresh' content='5'>";   // le navigateur redemande la page toutes les 5 s
  html += "</head><body style='font-family:sans-serif'>";
  html += "<h1>Station météo</h1>";
  if (erreur_capteur) {
    html += "<p style='color:#c00'><b>Erreur de lecture du DHT11 !</b></p>";
  } else {
    html += jauge("Température", temperature, 0, 50, 1, "°C", "#c2410c");
    html += jauge("Humidité", humidite, 0, 100, 0, "%", "#2b5fd6");
  }
  html += "<p>Dernière mesure il y a " + String((millis() - derniereMesure) / 1000) + " s</p>";
  html += "<h2>Historique (" + String(nbMesures) + " mesures, 30 min au maximum)</h2>";
  html += courbe();
  html += "<p><a href='/mesures.csv'>Télécharger les mesures (fichier CSV)</a></p>";
  html += "</body></html>";
  return html;
}
 
// Écrit un nombre avec une virgule (format attendu par un tableur en français)
String virgule(float v) {
  String s = String(v, 1);
  s.replace(".", ",");
  return s;
}
 
// Appelée quand le navigateur demande l'adresse /
void handleRoot() {
  server.send(200, "text/html; charset=utf-8", page());
}
 
// Appelée quand le navigateur demande l'adresse /mesures.csv : envoie l'historique en fichier CSV
void handleCSV() {
  String csv = "\xEF\xBB\xBF";           // marque UTF-8 : le tableur affiche bien les accents
  csv += "temps (s);temperature (°C);humidite (%)\n";
  for (int i = 0; i < nbMesures; i++) {
    csv += String(histTemps[i]) + ";" + virgule(histT[i]) + ";" + virgule(histH[i]) + "\n";
  }
  server.sendHeader("Content-Disposition", "attachment; filename=mesures.csv");   // à télécharger
  server.send(200, "text/csv; charset=utf-8", csv);
}
 
void setup() {
  Serial.begin(115200);
  dht.begin();                           // démarrer le capteur
 
  WiFi.begin(ssid, password);            // connexion au Wi-Fi
  Serial.print("Connexion au Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println();
  Serial.print("Adresse IP : ");
  Serial.println(WiFi.localIP());        // adresse à taper dans le navigateur
 
  server.on("/", handleRoot);            // adresse -> fonction
  server.on("/mesures.csv", handleCSV);
  server.begin();                        // démarrage du serveur web
 
  mesurer();                             // première mesure
  derniereMesure = millis();
}
 
void loop() {
  server.handleClient();                 // traite les requêtes des navigateurs
 
  // une mesure toutes les 5 s, sans bloquer le serveur web
  if (millis() - derniereMesure >= PERIODE) {
    derniereMesure = millis();
    mesurer();
  }
}
