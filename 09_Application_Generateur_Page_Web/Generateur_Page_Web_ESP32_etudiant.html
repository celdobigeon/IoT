Générateur de tableau de bord pour l'ESP32

Déclarez ce qui est branché sur la carte, puis composez le tableau de bord : pour chaque bloc, choisissez la valeur à afficher et sa forme (jauge, cadran, thermomètre, courbe…). L'aperçu fonctionne avec des mesures simulées. Téléchargez ensuite le programme Arduino complet : il n'y a rien à programmer.

Mode d'emploi
  1. Regardez l'exemple TP LED pour comprendre le principe, puis partez d'une page vide pour créer votre propre tableau de bord.
  2. Ma carte : ajoutez ce qui est branché (capteur DHT11, potentiomètre, bouton, LED…) et saisissez le Wi-Fi. Vérifiez que la broche choisie pour chaque composant est bien celle où il est câblé : le programme ne commande que la broche indiquée ici.
  3. Blocs : cliquez sur « Ajouter un bloc », choisissez une forme dans la galerie, puis la valeur à afficher. « Changer de forme » garde la valeur et change le dessin.
  4. Essayez l'aperçu : bougez les curseurs de simulation, cliquez sur les boutons du tableau de bord.
  5. Téléchargez le programme (si le téléchargement ne démarre pas, cliquez sur « Copier le programme » et collez-le dans un nouveau croquis), ouvrez le fichier .ino dans l'Arduino IDE (acceptez qu'il le range dans un dossier du même nom), choisissez la carte DOIT ESP32 DEVKIT V1 et téléversez.
  6. Moniteur série à 115200 bauds : tapez l'adresse IP affichée dans le navigateur d'un ordinateur ou d'un téléphone du même Wi-Fi.
  7. La LED ne s'allume pas ? Regardez le moniteur série après un clic. commande ON … lue = 1 : la carte a bien allumé la broche, vérifiez le câblage (broche, sens de la LED, résistance). Aucune ligne : la carte n'a pas reçu le clic.
