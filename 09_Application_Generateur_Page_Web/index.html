Comment l'utiliser

  1. Ouvrez le générateur en cliquant sur son nom, ou téléchargez-le pour travailler sans connexion : enregistrez le fichier, puis double-cliquez dessus, il s'ouvre dans votre navigateur.
  2. Regardez l'exemple « TP LED » pour comprendre le principe, puis choisissez « Page vide » pour créer votre propre tableau de bord.
  3. Ma carte : ajoutez ce qui est branché sur l'ESP32 (capteur DHT11, potentiomètre, bouton, LED…). Vérifiez que chaque broche choisie est bien celle de votre câblage, puis saisissez le nom et le mot de passe du Wi-Fi.
  4. Ajoutez des blocs : « Ajouter un bloc », choisissez une forme dans la galerie (jauge, thermomètre, courbe, voyant…), puis la valeur à afficher. « Changer de forme » garde la valeur et change le dessin.
  5. Testez dans l'aperçu : bougez les curseurs de simulation, cliquez sur le voyant ou les boutons de la page.
  6. Téléchargez le programme (.ino) et ouvrez-le dans l'Arduino IDE (acceptez qu'il le range dans un dossier du même nom). Si le téléchargement ne démarre pas, utilisez « Copier le programme » et collez-le dans un nouveau croquis. Choisissez la carte DOIT ESP32 DEVKIT V1 et téléversez.
  7. Ouvrez le moniteur série à 115200 bauds : tapez l'adresse IP affichée dans le navigateur d'un téléphone ou d'un ordinateur connecté au même Wi-Fi.

Votre travail est gardé dans le navigateur que vous utilisez. Pour le reprendre sur un autre ordinateur, cliquez sur « Enregistrer mon tableau de bord (.json) », puis, sur l'autre ordinateur, sur « Ouvrir… ».
